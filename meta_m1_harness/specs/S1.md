## Exakte Namen

`models.py`:

- `class AbstainStage(str, Enum)`: Werte `RESEARCH_EMPTY="research_empty"`, `GATE="gate"`,
  `VETO="veto"`, `DEBATE="debate"`, `ERROR="error"`.
- `class AbstainReason(str, Enum)`: `REASON_NO_CANDIDATES`, `REASON_GATE_TIME_WINDOW`,
  `REASON_GATE_CONSTRAINTS`, `REASON_GATE_SIZING`, `REASON_GATE_DIRECTION`,
  `REASON_VETO_SPREAD`, `REASON_VETO_MOMENTUM`, `REASON_VETO_STATUS_WINDOW`,
  `REASON_VETO_POSITION_CONFLICT`, `REASON_DEBATE_ABSTAIN`, `REASON_ERROR_FAILCLOSED`,
  `REASON_UNCLASSIFIED` — 12 Werte total, jeder Wert = Enum-Name in lowercase.
- `@dataclass(frozen=True) class AbstainRecord`: Felder `record_id: str`,
  `created_utc: str`, `epic: str | None`, `stage: AbstainStage`, `reason: AbstainReason`,
  `detail: str = ""`, `context_json: str = "{}"`, `lesson: str | None = None`,
  `lesson_extracted: bool = False`. Klassenmethode `new(...) -> AbstainRecord`
  (generiert `record_id` via `uuid4`, `created_utc` als UTC-ISO-Timestamp). Methode
  `to_row() -> tuple`. Klassenmethode `from_row(row) -> AbstainRecord` (Inverse von `to_row`).

`exceptions.py`:
- `class AbstainLessonError(Exception)` — Basisklasse.
- `class AbstainStoreError(AbstainLessonError)` — Persistenzfehler.

## Tests

`test_models.py` deckt ab:
- Konstruktion von `AbstainRecord` mit allen Feldern.
- Frozen-Verhalten — Mutation eines Feldes nach Konstruktion wirft.
- Enum-Vollständigkeit — genau 12 `AbstainReason`-Werte.
- `new()`-Defaults — `lesson is None`, `lesson_extracted is False`, `record_id`/`created_utc`
  automatisch gesetzt und plausibel (UUID-Form, ISO-Form).
- `to_row()`/`from_row()`-Roundtrip — ein Record durch beide Richtungen ist identisch.
