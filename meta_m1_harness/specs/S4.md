## Ziel

Die **einzige AI-Naht** dieses Moduls: ein optionaler LLM-Aufruf, der aus einem Abstain-Record
eine kurze Lehre extrahiert. Spiegelt das P7-Reward-Muster dieses Repos: default aus, wirft
nie in den Aufrufer, jeder Fehler wird zu `None` + einem kritischen Log-Eintrag.

## Exakte Namen

- `class AbstainLLM(Protocol)` mit einer Methode
  `def complete(self, prompt: str, timeout_s: float) -> str`.
- `def build_abstain_prompt(record: AbstainRecord) -> str` — deterministisch, enthält
  `reason`/`stage`/`detail` aus dem Record, fordert im Prompt-Text explizit **eine** Lehre in
  **maximal zwei Sätzen**, auf Deutsch.
- `def validate_abstain_lesson(text: str) -> str` — `strip()`t den Text, verlangt
  nicht-leer, ≤300 Zeichen, ein einzeiliger Absatz (kein `\n`). Verstoß → wirft
  `AbstainLessonError`.
- `def reflect_abstain(record: AbstainRecord, llm: AbstainLLM | None = None, timeout_s: float = 20.0) -> str | None`:
  - `llm is None` → gibt sofort `None` zurück (Default-aus-Prinzip, kein Call).
  - Sonst: ruft `llm.complete(build_abstain_prompt(record), timeout_s)` auf, validiert das
    Ergebnis über `validate_abstain_lesson`, gibt den validierten String zurück.
  - **Jeder Fehler** (LLM-Exception, Validierungsfehler, Timeout) → `logger.critical(...)` +
    Rückgabe `None`. Die Funktion **wirft nie**.

## Tests

`test_reflect.py` — **nur Mock-LLM, kein echtes Netz**:
- `llm=None` → `reflect_abstain(...)` gibt `None` zurück, kein Call versucht.
- Happy Path — Mock-LLM gibt validen Text zurück → derselbe Text kommt zurück.
- Validator-Reject — Mock-LLM gibt zu langen Text (>300 Zeichen) zurück → `None`,
  `logger.critical` aufgerufen (via `caplog`).
- Validator-Reject — Mock-LLM gibt leeren String zurück → `None`, kritisch geloggt.
- LLM wirft eine Exception → `None`, kritisch geloggt, keine Exception propagiert.
- `timeout_s`-Parameter wird unverändert an `llm.complete(...)` durchgereicht (Assertion auf
  dem Mock-Call-Argument).
