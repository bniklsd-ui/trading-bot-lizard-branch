## Ziel

Ein Sink, der die Bausteine S1–S4 zu einem Best-Effort-Pipeline-Schritt verbindet
(klassifizieren → persistieren → optional reflektieren → Lehre setzen), plus eine
minimal-invasive Wiring-Naht im Executor der bestehenden Phase-5-Ausführungsschicht
(`phase5_execution/`), nach dem Muster des dort bereits vorhandenen `reward_sink`.

> **[VERIFY-FORK]** Der exakte Symbolort in `phase5_execution/` (welche Funktion/Klasse die
> NO_TRADE-Rückgabepfade des Executors durchläuft) ist beim Ausführen im Fork gegen den
> tatsächlichen Code zu verifizieren — nicht blind annehmen.

## Exakte Namen

`sink.py`:
- `class AbstainSink(Protocol)` mit `def on_no_trade(self, cycle_outcome: Mapping[str, Any]) -> None`.
- `class AbstainLessonSink`:
  - `__init__(self, store: AbstainStore, llm: AbstainLLM | None = None)`.
  - implementiert `on_no_trade(self, cycle_outcome: Mapping[str, Any]) -> None`:
    `classify_abstain(cycle_outcome)` → `store.insert(record)` → optional
    `reflect_abstain(record, llm)` → falls eine Lehre zurückkommt, `store.set_lesson(...)`.
  - **Best-effort:** wirft nie in den Aufrufer — jeder interne Fehler wird `logger.critical`
    geloggt und verschluckt.

Executor-Naht in `phase5_execution/`:
- Neuer optionaler Parameter `abstain_sink: AbstainSink | None = None` an der Stelle, die die
  NO_TRADE-Rückgabepfade durchläuft (**[VERIFY-FORK]** exakte Signatur).
- **Default `None` ⇒ Verhalten bit-identisch zum Ist-Zustand** — das ist beweispflichtig
  (siehe Tests unten), nicht nur behauptet.
- Ist `abstain_sink` gesetzt, wird `on_no_trade(cycle_outcome)` auf jedem NO_TRADE-Pfad
  aufgerufen, auf dem Trade-Pfad **nie**.

## Tests

`test_sink.py`:
- `AbstainLessonSink.on_no_trade(...)` — klassifiziert, persistiert, ruft optional reflect,
  setzt Lehre wenn vorhanden. Store/LLM sind Mocks.
- Sink-Exception (z. B. Store wirft) erreicht den Aufrufer **nicht** — best-effort bestätigt.

`phase5_execution/tests/` (**[VERIFY-FORK]** — Stub/Mock-Executor-Setup nach dem Muster der
dort bereits bestehenden Tests):
- Sink-Aufruf auf NO_TRADE-Pfaden bestätigt.
- **Kein** Aufruf auf dem Trade-Pfad.
- Default-`None`-Bit-Identität — mit `abstain_sink=None` verhält sich der Executor exakt wie
  vor dieser Änderung (Regression der bestehenden P5-Suite bleibt vollständig grün).
