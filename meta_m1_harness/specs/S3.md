## Exakte Namen

`class AbstainStore`:
- `__init__(self, db_path: Path)` — öffnet eine eigene `sqlite3.Connection` auf `db_path`.
- `ensure_schema(self) -> None` — `CREATE TABLE IF NOT EXISTS abstain_records` mit Spalten
  exakt entsprechend `AbstainRecord.to_row()`'s Tupel-Reihenfolge, Primary Key `record_id`.
- `insert(self, record: AbstainRecord) -> None` — idempotent via `INSERT OR IGNORE`.
- `recent(self, limit: int = 20) -> list[AbstainRecord]` — newest first (nach `created_utc`
  absteigend).
- `recent_lessons(self, limit: int = 5) -> list[str]` — nur Records mit
  `lesson_extracted=1` und nicht-null `lesson`, newest first, gibt die Lesson-Strings zurück.
- `set_lesson(self, record_id: str, lesson: str) -> None` — setzt `lesson` und
  `lesson_extracted=True` auf dem Record mit diesem `record_id`.
- `close(self) -> None` — schließt die Connection.
- Context-Manager-Protokoll (`__enter__`/`__exit__`), `__exit__` ruft `close()`.

Fehler (kaputter Pfad, SQLite-Fehler) → `AbstainStoreError` (aus S1's `exceptions.py`).

## Tests

`test_store.py`:
- `tmp_path`-DB — Schema-Erzeugung über `ensure_schema()`.
- `insert` + `recent()` — Reihenfolge (newest first) korrekt.
- Idempotenz — doppelter `insert()` desselben `record_id` wirft nicht, erzeugt keine
  Duplikate.
- `set_lesson()` + `recent_lessons()`-Filter — nur Records mit `lesson_extracted=True`
  erscheinen.
- Fehlerpfad — ein kaputter/nicht schreibbarer Pfad führt zu `AbstainStoreError`.
